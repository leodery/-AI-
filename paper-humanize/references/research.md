# 来源与综合取舍

日期：2026-11-03。阅读以下 GitHub main 分支 SKILL.md；未运行来源代码。本文为概念提炼与原创组织，不复制来源正文，不对来源整体质量作保证。

| 来源 | 采用的启发 | 调整 |
|---|---|---|
| [zh-scientific-humanizer](https://github.com/XuanjinZhu/zh-scientific-humanizer/blob/main/SKILL.md) | 科研术语保护、章节差异、证据强度 | 从植物科研场景扩展为按学科与研究类型处理 |
| [humanizer-academic-zh](https://github.com/cangtianhuang/humanizer-academic-zh/blob/main/SKILL.md) | 中文句法自然、术语稳定、减少空泛评价 | 不采用固定标点限额，不把三项分类视为缺陷 |
| [manuscript-writing](https://github.com/YSLAB-ai/manuscript-writing/blob/main/SKILL.md) | 区分审阅与修改，未核实主张不能靠加限定词解决 | 将实质改动与证据缺口从纯语言改动中辨认出来 |
| [citation-check](https://github.com/scdenney/open-science-skills/blob/main/plugin/skills/citation-check/SKILL.md) | 引文存在、标识符匹配与支持关系须分别判断 | 不默认 APA，不对每次局部润色强制全量核查 |

citation-check 自述其核验工作流参考 Cheng-I Wu 的 Academic Research Skills for Claude Code（CC BY-NC 4.0）；此处记录其来源关系。没有复制该工作流的原文、代码或表格模板。

综合出的重点：写作质量来自明确问题、证据与解释的匹配；自然表达需要保留学科语体；不能通过机械同义替换损伤术语，也不能通过虚构细节填补证据。新增了从选题到起草的材料不足分流，避免将提案写成已完成研究。

只验证技能结构与人工检查边界、案例和引用链接，未在真实论文上完成效果测试，也未对 AI 检测结果进行测试。
